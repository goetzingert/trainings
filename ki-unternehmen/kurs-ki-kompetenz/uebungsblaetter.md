# Übungsblätter KI-Kompetenz für Ihr Team

## Hinweise für Trainer

Elf Übungsblätter für den Schulungstag, in der Reihenfolge des Foliensatzes. Jedes Blatt einzeln ausdrucken; die Lösungen am Ende nicht an Teilnehmende ausgeben. Alle Namen, Firmen, Kundennummern und Zahlen sind frei erfunden.

| Blatt | Thema | Einheit | Sozialform | Zeit |
| --- | --- | --- | --- | --- |
| 1 | KI zum Stolpern bringen | LE 1 | Gruppen à 3 | 15 min |
| 2 | Fallkarten Ampel | LE 2 | Gruppen à 3–4 | 20 min |
| 3 | Mein erster R-A-K-F-Prompt | LE 3 | Einzeln | 25 min |
| 4–9 | Praxisstationen 1–6 | LE 4 | Paare | je 15 min |
| 10 | Fehlersuche | LE 5 | Einzeln oder Paare | 20 min |
| 11 | Transferplan | LE 6 | Einzeln | 25 min |

Vor Inhouse-Terminen: Blatt 2 und die Ampel an die KI-Richtlinie des Unternehmens anpassen, Stationen nach Möglichkeit durch anonymisierte Fälle aus den Abteilungen der Teilnehmenden ersetzen.

## Übungsblatt 1: Bringen Sie die KI zum Stolpern

**Ziel:** Erleben, wie überzeugend KI auch falsche Antworten formuliert. **Zeit:** 15 Minuten in Gruppen à 3. Arbeiten Sie nur mit erfundenen oder öffentlichen Angaben.

| Versuch | Ihre Frage an die KI | Was hat die KI geantwortet? | Stimmt das? Woher wissen Sie es? |
| --- | --- | --- | --- |
| A: ein Preis oder eine Regel Ihres Unternehmens | | | |
| B: eine Vorschrift, die es nicht gibt | | | |
| C: eine Rechenaufgabe mit Zwischenschritten, z. B. eine Rabattstaffel | | | |

**Unser schönster Fehler:**

**Woran hätten wir ihn erkannt, ohne die richtige Antwort schon zu kennen?**

## Übungsblatt 2: Fallkarten Ampel

**Auftrag:** Ordnen Sie jede Situation Grün, Gelb oder Rot zu und begründen Sie kurz. Markieren Sie, wo Sie sich in der Gruppe uneinig waren. **Zeit:** 20 Minuten. Für die Kartenvariante die Zeilen ausschneiden.

Grün = öffentlich · Gelb = intern, nur freigegebene Business-Tools · Rot = vertraulich (Kunden-, Personaldaten, Geschäftsgeheimnisse), nur wenn ausdrücklich freigegeben

| Nr. | Situation | Grün / Gelb / Rot | Begründung |
| --- | --- | --- | --- |
| 1 | Ich lasse mir einen Fachartikel zu einem neuen Produktstandard in einfacher Sprache zusammenfassen. | | |
| 2 | Ich kopiere eine Kundenbeschwerde mit Name, Adresse und Bestellnummer in einen kostenlosen Online-Chatbot, um sie zusammenzufassen. | | |
| 3 | Ich lasse mir im freigegebenen Business-Tool eine Gliederung für ein internes Konzept zur Lagerumstellung vorschlagen. | | |
| 4 | Ich bitte die KI, eine Stellenanzeige geschlechtergerecht umzuformulieren. | | |
| 5 | Ich lade die Gehaltsliste der Abteilung hoch, um eine Auswertung zu erstellen. | | |
| 6 | Ich lasse mir ein Besprechungsprotokoll aus meinen Stichpunkten erstellen; darin stehen nur Funktionen, keine Namen. | | |
| 7 | Ich nutze die KI auf meinem privaten Handy, um eine E-Mail an einen Kunden zu formulieren, ohne Namen. | | |
| 8 | Ich frage die KI, wie lange ein Kunde den Kauf widerrufen kann, und schreibe die Antwort so in die E-Mail. | | |
| 9 | Ich lasse unsere Kalkulation für ein großes Angebot von der KI auf Fehler prüfen. | | |

## Übungsblatt 3: Mein erster R-A-K-F-Prompt

**Ampel-Einstufung nach dem Anonymisieren:** Grün / Gelb / Rot

| --- | --- | --- |

| Format | Länge, Gliederung, Ton, Anrede | |

| Runde | Was ich nachgeschärft habe | Was besser wurde |
| --- | --- | --- |
| 1 | | |

Tipp: Fragen Sie die KI am Ende: „Welche Informationen fehlen dir noch?“ und „Welche Schwächen hat dein Entwurf?“

## Übungsblätter 4–9: Praxisstationen

Arbeiten Sie zu zweit, je 15 Minuten pro Station, mindestens vier von sechs Stationen. Notieren Sie an jeder Station: **Zeit gespart?** ja / teils / nein · **Was mussten wir nacharbeiten?**

### Übungsblatt 4 · Station 1: Verständliche Sprache

Formulieren Sie die AGB-Klausel so um, dass sie eine Kundin ohne juristische Vorkenntnisse versteht. Der Inhalt darf sich nicht ändern.

> „Der Auftraggeber ist verpflichtet, die gelieferte Ware unverzüglich nach Ablieferung zu untersuchen und erkennbare Mängel binnen einer Frist von fünf Werktagen schriftlich anzuzeigen; unterlässt er die Anzeige, gilt die Ware als genehmigt, es sei denn, es handelt sich um einen Mangel, der bei der Untersuchung nicht erkennbar war.“

Bonus: Lassen Sie die KI prüfen, ob in Ihrer Fassung eine Information verloren ging.

### Übungsblatt 5 · Station 2: Zusammenfassen

Fassen Sie den Bericht für die Geschäftsführung zusammen: höchstens fünf Stichpunkte und ein Satz „Empfehlung“.

> Die Kundenbefragung im dritten Quartal ergab 412 auswertbare Antworten. Mit der Produktqualität sind die Kundinnen und Kunden weiterhin sehr zufrieden (Durchschnitt 4,3 von 5). Kritisch gesehen werden die Lieferzeiten: 38 % der Befragten gaben an, dass mindestens eine Lieferung im Quartal verspätet war. Besonders Kunden aus dem Handwerk wünschen sich ein Online-Portal, in dem sie den Lieferstatus verfolgen können. Die telefonische Service-Hotline wurde ausdrücklich gelobt, vor allem für kurze Wartezeiten. Die Preise werden überwiegend als angemessen bewertet, einzelne Großkunden fordern jedoch Staffelrabatte. Der Vertrieb schlägt vor, ein Liefer-Tracking im Kundenportal einzuführen, sofern das Budget dafür im ersten Quartal des kommenden Jahres freigegeben wird.

### Übungsblatt 6 · Station 3: Protokoll

Erstellen Sie aus den Stichpunkten ein Ergebnisprotokoll als Tabelle: TOP · Ergebnis · Verantwortlich · Termin.

```
Teambesprechung Vertrieb Innendienst 03.06.
- Rückstau Angebotsanfragen >2 Tage, Vorschlag: Standardangebote als Vorlage -> Teamleitung prüft bis Ende Monat
- neues Preisblatt ab 1.7., alte PDFs aus dem Laufwerk löschen
- Urlaubsplanung Sommer: Liste im Teams-Kanal, eintragen bis 15.6.
- CRM-Absturz beim Export, Ticket existiert schon (IT fragt nach)
- nächstes Treffen 01.07.
```

### Übungsblatt 7 · Station 4: Kundenanfrage

Erstellen Sie einen freundlichen Antwortentwurf. Fragen Sie die KI zuerst: „Welche Informationen fehlen dir, um korrekt zu antworten?“

> „Hallo, wir haben letzte Woche 40 Pumpen bestellt und brauchen jetzt dringend 10 weitere. Können Sie die bis Freitag liefern? Und gilt dann noch der Rabatt aus der ersten Bestellung? Ach ja, kann die Rechnung diesmal an unsere Niederlassung in Trier gehen? Grüße, M. Beispiel“

Setzen Sie für Liefertermin, Rabatt und Rechnungsanschrift Platzhalter ein. Was davon müssen Sie im Haus klären, bevor Sie antworten?

### Übungsblatt 8 · Station 5: Entscheidungsvorlage

Erstellen Sie die Gliederung und einen ersten Entwurf des Abschnitts „Ausgangslage“ für eine Entscheidungsvorlage an die Geschäftsführung.

> Thema: Anschaffung von zwei E-Lastenrädern für den Innenstadt-Kundendienst. Kosten ca. 14.000 €, Förderung bis 25 % über ein Landesprogramm möglich, Antragsfrist in 6 Wochen. Ziel: Kurzstrecken in der Innenstadt ohne Transporter, kein Parkplatzsuchen. Bisher 2 Transporter, einer davon muss 2027 ersetzt werden.

Gliederung: Anlass · Ausgangslage · Optionen · Kosten und Nutzen · Empfehlung (oder die Gliederung Ihres Unternehmens).

### Übungsblatt 9 · Station 6: Recherche-Falle

Fragen Sie die KI: „Wie lange müssen wir als GmbH Rechnungen und Buchungsbelege aufbewahren?“

| Prüffrage | Ihre Notiz |
| --- | --- |
| Nennt die KI eine konkrete Frist und Vorschrift? | |
| Stimmt sie? Geprüft an welcher Quelle? | |
| Woran erkennen Sie, wie aktuell das Wissen der KI ist? | |
| Wen fragen Sie im Unternehmen verbindlich (Steuerberatung, Buchhaltung)? | |

## Übungsblatt 10: Fehlersuche

**Auftrag:** Die drei Texte wurden mit KI erstellt und ungeprüft übernommen. Insgesamt stecken sieben Fehler darin. Unterstreichen Sie jeden Fehler und ordnen Sie ihn einem Buchstaben zu: **F**akten · **A**dressat · **K**onsistenz · **T**ransparenz und Fairness. **Zeit:** 20 Minuten.

### Text A: Antwort an eine Kundin (Onlinekauf, Privatkundin)

> Sehr geehrte Frau Beispiel,
>
> vielen Dank für Ihre Nachricht. Sie können Ihren Kauf vom 12. September selbstverständlich widerrufen. Gemäß § 3 des Widerrufsfristengesetzes beträgt die Frist 30 Tage. Senden Sie uns dazu einfach eine kurze Erklärung per E-Mail.
>
> Mit freundlichen Grüßen

### Text B: Zusammenfassung für die Geschäftsführung

Grundlage ist die Kundenbefragung auf Übungsblatt 5.

> - Hohe Zufriedenheit mit der Produktqualität (4,3 von 5).
> - Kritisch: 48 % meldeten mindestens eine verspätete Lieferung.
> - Die Service-Hotline wird wegen langer Wartezeiten kritisiert.
> - Großkunden wünschen Staffelrabatte.
> - Empfehlung: Liefer-Tracking im Kundenportal sofort einführen.

## Lösungen für Trainer

Nicht an Teilnehmende ausgeben. Die Ampel-Lösungen gelten für die Standardregel und müssen an die KI-Richtlinie des Unternehmens angepasst werden.

### Blatt 9: Recherche-Falle

Für Buchungsbelege wurde die Aufbewahrungsfrist durch das Bürokratieentlastungsgesetz IV ab 2025 von zehn auf acht Jahre verkürzt; für Bücher, Jahresabschlüsse und andere Unterlagen gelten weiter andere Fristen. Modelle mit älterem Wissensstand nennen oft pauschal zehn Jahre. Vor dem Einsatz den aktuellen Stand prüfen. Botschaft: Für verbindliche Auskünfte ist Steuerberatung oder Buchhaltung zuständig, nicht die KI.
